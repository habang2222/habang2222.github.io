# change healthcare 랜섬웨어 사고

IT담당자가 원격으로 컴퓨터에 접속할 수 있는 프로그램인 screenConnect에 심각한 결함이 있었습니다. 업데이트가 배포된 지 며칠이 지났지만 change/uhc는 아무런 조치를 취하지 않았습니다 이로 인해 해커들은 사실상 해킹 없이도 새 사용자를 만들어 모든 권한을 획득할 수 있었습니다 change는 업데이트가 배포된지 충분히 시간이 지났으므로 문제를 해결 하거나 최소한 screenconnect 를 비활성화 할 수 있었지만 아무런 조치도 취하지 않아서 문제가 생겼습니다

change healthcare는 미국 내 의료 서비스 제공 업체와 보험사를 위한 수익 주기 관리 및 지불 처리 서비스를 제공하는 의료 기술 회사 입니다

unitedhealth gruoup 의 ceo witty는 2월에 발생한 change healthcare 랜섬웨어 공격과 관련하여 미 의회에서 자신의 조직이 공격자의 랜섬웨어 요구 금액을 지불했다고 인정 하였습니다

해커 조직은 블랙캣 비트코인을 통해 2200만 달러를 지급 받은것으로 보고되었습니다

witty는 앤섬웨어 비용을 지불 했음에도 불구하고 change healthcare가 데이터를 되찾지 못했다다

핸섬웨어 공격에서 흔히 발생하는 일입니다 그래서 ibm을 비롯한 많은 전문가들이 랜섬웨어 비용을 지불할 것을 권고 하지 않는 이유중 하나 입니다  적절한 백업 및 데이터 복구 프로세스를 통해 조직은 자체 데이터를 신속하게 복원하고 비지니스 중단을 줄일 수 있습니다

(2023 한 해 동안 change healthcare 와 같이 랜섬 웨어로 지불된 금액은 상상 최고치인 11억 달러에 달했습니다)

CEO의 증언에 따르면 블랙캣은 자격 증명을 이용하여 change healthcare citrix 포털에 원격으로 액세스하였고 이를통해 원격 테스크톱 액세스가 가능해 졌습니다 이 포털은 다단계 인증을 사용 하지 않았습니다 그런 다음 블랙캣은 change healthcare 의 정보 기술 환경에 랜섬웨어를 배포하여 change의 모든 시스템을 암호화 하여 엑세스 할 수 없게 만들었습니다 

change 의 환경 외부에서 다른 unitedhealth group 시스템으로 확산 되는것 방지 하였습니다

미국 의학 협회의 설문조사에 따르면 change healthcare 침해의 광범위한 영향으로 인해 임상의 5명 중 4명이 손실을 겪고 77%가 서비스 중단을 경험한 것으로 밝혀졌습니다

change healthcare은 이번 공격으로 8억 7200만 달러의 손실을 입었으며 손실액이 10억달러 이상으로 늘어날 것으로 예상 하고 있습니다

CEO는 의회에 자신이 랜섬웨어를 지불하기로 결정했다고 말하였습니다 랜섬웨어 요구 금액을 지불한 후에도 위협행위자들은 여전히 다크웹에서 데이터를 공유하겠다고 협박했습니다

블랙캣 계열 단체인 랜선섬허브는 도난 당한 데이터중 적어도 일부를 유출하고 추가 적인 탈취를 시도하여 복구를 더욱 복잡하게 만들었습니다 랜섬 허브는 스크린샷을 다크웹의 최고 입찰자에게 공유했습니다 change healthcare 와 같은 대규모 유출에서는 이중 랜섬웨어 시도가 드문 일이 아닙니다 이는 많은 몸값 지불에 경고하는 이유중 하나 입니다

#### 방식

IT담당자가 원격으로 컴퓨터에 접속할 수 있는 프로그램인 screenConnect에 심각한 결함이 있었습니다. 업데이트가 배포된 지 며칠이 지났지만 change/uhc는 아무런 조치를 취하지 않았습니다 이로 인해 해커들은 사실상 해킹 없이도 새 사용자를 만들어 모든 권한을 획득할 수 있었습니다

탈취된 계정 정보 사용
→ MFA 없는 Citrix 원격 접속 포털 접근
→ 내부망 이동
→ 데이터 탈취
→ 약 9일 뒤 랜섬웨어 배포
→ 의료 청구·결제 시스템 대규모 장애

#### 방어

가장 큰 문제는 mfa부재 입니다 

- mfa : milti-factor authentication
    - 다중 인증 요소
    - 로그인 할때 비밀번호 하나만 사용하는것이 아니라 추가 인증을 하나 더 요구 하는 방식입니다

방어 방법으로는

모든 원격 접속 서비스에 MFA 적용
관리자 계정은 별도 MFA 강제
오래된 계정, 미사용 계정 비활성화
비밀번호 재사용 금지
로그인 실패/해외 로그인 탐지

또 원격 접속 포털을 인터넷에 그대로 노출하지 않기 입니다 

change healthcare 사고에서 공격자는 원격 접속 포털을 통해 들어온 것으로 알려져있습니다

VPN, Citrix, RDP, VDI는 인터넷 전체에 공개하지 않기
허용된 IP만 접속 가능하게 제한
Geo-blocking 적용
관리자 접속은 별도 Bastion Host 사용
접속 로그를 SIEM/EDR로 수집

특히 RDP Citrix VPN 관리자 웹 콘솔 이 외부에 열려 있으면 공격작 계속 로그인 시도 할 수 있습니다

랜섬웨어 방어 방법은 내부망 분리 입니다

change Healthcare 사고도 단일 시스템 장액가 아니라 의료 청구 결제 시스템 전체에 큰 영향을 줬습니다

계정 하나 하나의 권한을 분리해 계정 하나를 탈취 했을때 권한을 일부만 가지고 있게 해서 많은 일을 할 수 없게 하면 됩니다

# 미국 이란 전쟁 이란 해커 그룹 stryker 해킹

2026년 2월 26일 오만을 통한 미국 이란의 핵 협상이 결렬, 28일 미국과 이스라엘의 기습 타격(핵시설 군사기지 대규모 본토 폭격) 이러한 배경을 바탕으로 이란 배후의 해커 그룹 한다라가 미국의 의교기기 제조사인 스트라이커를 공격후 텔레그램채널과 다크웹 데이터 유출 사이트에 데이터 중 일부 샘플을 공개하는 사건이 일어났습니다

이 공격으로 인해 선 세계 스트라이커 시스템에 장애가 발생해 업무 수행이 중단되었습니다 회사 시스템에 접혹한 의료기기의 자료가 삭제되는 현상이 발생, 사측에서 직원들에게 회사 네트워크에 접속하지 말라는 지시를 내렸습니다

스트라이커는 병원에 사용되는 장비를 생산하는 의료기긱 생산 업체로 한국을 포함해 61개국에 판매되고 있습니다 생산하는 장비로는 정형외과용 장비 수술도구 응급처치용 장비, 중환자용 일회용 장비 등 광범위 합니다

이 공격으로 인해 20만개 이상의 시스템, 서버, 모바일 기기가 초기화 되고 50 테라바이트 의 데이터가 유출됐습니다

#### 방식

종류

- 기존 랜섬웨어, 파괴형 악성코드 를 직접 유포하는 방식과 다름
- 정상적인 기업용 관리 도구를 무력화한 lotl 기법
    - lotl (living off the land) : 악성 코드를 새로 설치치 하는방식이 아니라 이미 컴퓨터나 서버에 원래 존재하는 정상 도구를 악용해서 공격 하는 기법
        - 예)
        
        | 정상 도구 | 원래 용도 | 공격자가 악용하면 |
        | --- | --- | --- |
        | `PowerShell` | 시스템 관리, 자동화 | 명령 실행, 파일 다운로드, 정보 수집 |
        | `cmd.exe` | 명령 프롬프트 | 내부 명령 실행 |
        | `wmic` / WMI | 원격 관리 | 다른 PC로 이동, 명령 실행 |
        | `certutil` | 인증서 관리 | 파일 다운로드, 인코딩/디코딩 |
        | `schtasks` | 작업 스케줄러 | 지속성 확보 |
        | `reg.exe` | 레지스트리 관리 | 자동 실행 등록 |
        | `rundll32.exe` | DLL 실행 | 악성 DLL 실행 |
        | `mshta.exe` | HTML Application 실행 | 스크립트 실행 |
    - 이러한 방법은 백신 입장에서는 원래 있는 정상 프로그램이라서 차단 하기 어렵습니다
    - 공격자는 탐지 회피가능 디스크에 악성 파일을 거의 남기지 않고 메모리나 명령어 중심으로 동작 가능, 관리자 행위처럼 위장 가능, 내부 이동에 유리 하다는 장점이 있습니다

#### 방어

lotl은 파워쉘을 무조건 막기 이런 방식으로 방어 하면 업무때도 사용을 못하기 때문에 

행위 기반 탐지를 하면 됩니다

예)

PowerShell이 갑자기 인터넷에서 파일 다운로드
PowerShell이 base64로 인코딩된 긴 명령 실행
일반 직원 PC에서 WMI로 다른 PC에 원격 명령 실행
schtasks로 수상한 자동 실행 등록
certutil이 인증서 작업이 아니라 파일 다운로드에 사용됨

이런건 정상 관리 작업과 다르게 의심하면 방어를 할 수 있었습니다

이란 연계 공격자들은 보통 vpn 원격접속, 클라우드 계정, 이메일 계정을 노립니다

MFA 강제
VPN / RDP / Citrix 외부 노출 최소화
관리자 계정과 일반 계정 분리
오래된 계정 삭제
비정상 로그인 탐지

# snowflake 관련 데이터 유출

미국의 클라우드 기반 데이터 솔루션 기업 클라우드로 받아온 여러 형태의 고객사 데이터를 etl(추출/변환/적재)과정을 거쳐 웨어 하우스로 변환 시키고 유니스토어로 워크로드를 특정 애플리케이션상에 통합하여 분석 예측 수익화 등의 솔루션을 제공합니다

웨어하우스 : 여러 곳에서 모은 데이터를 정리해서 저장해두고 분석할 수 있게 만든 큰 저장소

워크로드 : 처리해야하는 일의 종류와 양

유니스토어 : 여러 종류의 데이터를 하나의 저장소처럼 통합해서 다루는 저장 방식

스노우 플레이크 데이터 유출은 클라우드 기반 데이터 및 ai플랫폼인 snowflake lnc. 에 호스팅 된 고개 클라우드 환경에 대한 무단 접근과 관련된 2024년의 대규모 사이버 보안 사고입니다

이 유출은 수많은 유명 고객에게 영향을 미쳤습니다

이 공격으로 유출된 데이터

- 개인 식별 정보
- 의료 처방자 dea 번호
- 디지털 이벤트 티켓
- AT&T의 500억건 이상의 통화 기록

도난당한 데이터는 샤이니헌터 그룹에 의해 공격 당했으며 해커들을 정보 유출이나 판매를 하니 않는 대가로 몸값을 요구 하였습니다

#### 방식

환경 구성 및 액세스 방식의 취약점을 통해 최소 160개 조직이 공격 대상이 되었습니다

흐름

| 단계 | 설명 |
| --- | --- |
| 1 | 직원/협력사 PC가 인포스틸러 악성코드에 감염됨 |
| 2 | 브라우저나 도구에 저장돼 있던 Snowflake 계정 정보가 탈취됨 |
| 3 | 공격자가 그 계정으로 Snowflake 고객 환경에 로그인함 |
| 4 | MFA가 없어서 비밀번호만으로 접속이 가능했음 |
| 5 | 데이터베이스 안의 고객 정보, 거래 정보, 로그 등을 대량 조회함 |
| 6 | 데이터를 외부로 빼낸 뒤 판매하거나 피해 기업을 협박함 |

피해가 커진 이유는 MFA가 없는 계정이 많아서 아이디/비번만 얻으면 바로 로그인을할 수 있는것이 가장 큰 문제였습니다

#### 방어

역시나 MFA같은 방어 수단을 갗춰 놓았으면 벌어지지 않은 사고 였습니다
