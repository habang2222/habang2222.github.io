# Stryker 해킹 사고

[노션 원본 보기](https://app.notion.com/p/3840e129ee9b805eaf06d346e3dc09da?pvs=1)

### 1. 기업 개요

Stryker는 미국의 대표적인 의료기기 제조 기업이다. 정형외과용 장비, 수술 도구, 응급 처치 장비, 중환자용 장비 등 병원에서 사용하는 다양한 의료기기를 생산한다. 전 세계 여러 국가에 제품을 공급하고 있으며, 의료 현장과 직접 연결된 기업이라는 점에서 사이버 공격을 받을 경우 기업 내부 업무뿐 아니라 의료 공급망에도 영향을 줄 수 있다.

### 2. 주요 취약점 및 사고 원인

이 사건은 일반적인 랜섬웨어 감염보다는 기업용 관리 환경과 관리자 권한이 악용된 사고로 설명된다. Stryker는 공식적으로 내부 Microsoft 기업 환경에 장애가 발생했으며, 랜섬웨어나 일반적인 악성코드가 배포된 증거는 없다고 밝혔다.

따라서 이 사고의 핵심은 악성코드 자체보다 관리자 권한, 클라우드 관리 환경, 단말 관리 도구의 보안 문제라고 볼 수 있다. 공격자가 기업용 관리 도구나 관리자 계정을 장악하면, 별도의 악성코드를 설치하지 않아도 단말 초기화, 접근 차단, 권한 변경 같은 심각한 행위를 수행할 수 있다.

다만 공격자 측이 주장한 대규모 데이터 유출이나 장비 초기화 규모는 회사의 공식 확인 내용과 구분해서 다루어야 한다. 따라서 보고서에서는 해당 내용을 확정적으로 쓰기보다 "공격자 주장에 따르면" 또는 "일부 보도에 따르면"으로 표현하는 것이 적절하다.

### 3. 공격 전개 과정

일부 보도에서는 공격자가 Microsoft Intune과 같은 기업용 단말 관리 도구를 악용했을 가능성을 제기했다. Intune은 원래 회사가 직원의 노트북, 휴대폰, 태블릿 등을 관리하기 위해 사용하는 정상적인 관리 도구이다.

공격자가 이러한 관리 환경의 권한을 확보하면, 회사가 업무 목적으로 사용하는 기능을 공격에 악용할 수 있다. 예를 들어 단말 초기화, 계정 권한 변경, 보안 설정 변경, 접근 차단 같은 명령을 정상 관리 행위처럼 실행할 수 있다.

이러한 공격은 LOTL, 즉 Living off the Land 기법과 관련된다. LOTL은 새로운 악성코드를 설치하는 대신, 시스템에 원래 존재하는 정상 도구를 악용하는 방식이다. PowerShell, WMI, cmd, schtasks, certutil, Microsoft Intune 같은 도구가 대표적으로 악용될 수 있다.

공격 흐름은 다음과 같이 정리할 수 있다.

관리자 계정 또는 관리 도구 접근 권한 탈취
→ Microsoft 관리 환경 접근
→ 관리자 권한 악용
→ 단말 초기화 또는 접근 차단 명령 수행
→ 내부 업무 시스템 장애 발생
→ 공격자 측의 데이터 유출 주장 또는 협박

### 4. 대응 및 방어 방안

LOTL 방식의 공격은 정상 도구를 악용하기 때문에 단순히 특정 프로그램을 전부 차단하는 방식으로는 방어하기 어렵다. PowerShell이나 관리 도구는 실제 업무에도 필요하기 때문이다. 따라서 핵심은 도구 사용 자체를 막는 것이 아니라, 비정상적인 사용 행위를 탐지하는 것이다.

예를 들어 일반 직원 PC에서 갑자기 WMI로 다른 PC에 원격 명령을 실행하거나, PowerShell이 인터넷에서 파일을 다운로드하거나, 관리자가 아닌 계정이 대량의 장비 초기화 명령을 실행한다면 이상 행위로 탐지해야 한다.

주요 방어 대책은 다음과 같다.

- 관리자 계정에 강력한 MFA 적용
- 관리자 계정과 일반 업무 계정 분리
- Microsoft 365, Entra ID, Intune 관리자 권한 최소화
- Global Administrator 계정 수 최소화
- 관리자 권한 변경 이벤트 모니터링
- 대량 단말 초기화 명령 탐지
- PowerShell, WMI, certutil, schtasks 등의 비정상 사용 탐지
- EDR과 SIEM을 통한 행위 기반 탐지
- 중요 관리 콘솔 접근 위치 제한
- 클라우드 관리자 계정의 로그인 위치와 접속 기기 감시

이 사고는 악성코드만 막는다고 보안이 완성되는 것이 아니라는 점을 보여준다. 정상 관리 도구도 권한이 탈취되면 매우 위험한 공격 도구가 될 수 있다.
